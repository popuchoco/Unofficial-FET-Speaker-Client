# Unofficial FET Speaker Client

支援小狐狸與小愛講的獨立 Android 用戶端。App 在使用者裝置上執行，無須伺服器或遠傳會員帳號。AI 對話及 KKBOX 播放交由各家官方服務處理。

## 使用 Android 預覽版

1. 在「我的音箱」開啟 Android 藍牙設定，配對小狐狸或小愛講並選為媒體輸出。
2. 回到首頁查看 Android 提供的藍牙媒體輸出，以及語音助理狀態。
3. 首頁按「連結 ChatGPT」，在 OpenAI 官方頁面以自己的帳戶登入並授權。之後從首頁輸入或按「開始說話」提問；本機支援的生活指令留在手機處理，其他問題會在你送出後直接傳給 ChatGPT，回答由本機中文語音播放。Gemini 與 Claude 可從「服務設定」開啟官方頁面；若其 App 或網站支援分享回答，也可分享至愛狐說，由本機語音朗讀。
4. 如需測試音訊，展開「測試工具」。可測試中文語音播放、媒體按鍵及 BLE。首頁語音助理也支援本機時間、日期、農曆、四則與單位換算。

語音助理的產品目標是由音箱喚醒並聽取問題，再由音箱播放回答。目前從手機首頁開始離線收音，並可自動回答、使用 ChatGPT 與經藍牙音箱播放；音箱喚醒、按鍵觸發和音箱麥克風仍待兩款音箱集中驗收及整合。
試說「三分鐘後提醒我拿包裹」或「明天早上九點提醒我拿包裹」。提醒會留在這支手機，Android 通知可因省電設定延後。可從首頁「查看本機提醒」取消排程。

從首頁「家庭留言」錄製、儲存、播放或刪除語音留言。音檔只存在本 App 的私有目錄，離開頁面時會取消未儲存的錄音。留言播放遵守 Android 音訊焦點，短暫中斷後會接續播放，其他音訊永久取得焦點時會停止。

查空氣品質前，可在「服務設定 → 設定空氣品質資料來源」輸入環境部授權碼，再說「查空氣品質松山」。授權碼以 Android Keystore 加密保存在此裝置，只有主動查詢時才會送往環境部；儲存空白可移除授權碼。

查天氣可在「服務設定 → 設定天氣資料來源」輸入中央氣象署授權碼與預設鄉鎮，再說「明天天氣」或「臺北市信義區明天天氣」。授權碼以 Android Keystore 加密保存在此裝置，只在主動查詢時送往氣象署，地名在手機比對。

翻譯前，在「服務設定 → 設定 Papago 翻譯 API」填入自己從 Naver Cloud 申請的 Client ID 與 Secret，再說「把你好翻成日文」。文字會在你明確要求翻譯時送往 Papago；服務依字數收費，請先在 Naver Cloud 設定用量上限。譯文會嘗試使用手機已安裝的目標語言離線語音播放，並附 Papago 來源連結。

試說「一百美元換成臺幣」或「現金三百三十臺幣換美元」。主動查詢時會下載臺灣土地銀行官方 CSV，金額與幣別留在手機計算。語音會說明資料來源及買賣方向；換算結果僅供參考，實際成交以銀行當時牌告為準。

## 開發

需要 JDK 17 和 Android SDK 35。可用 Android Studio 開啟專案，或在設定 Android SDK 後執行以下指令。

```powershell
.\gradlew.bat testDebugUnitTest lintDebug
```

Android 版最低支援 Android 7.0。瀏覽器雛型仍可直接以瀏覽器開啟 `index.html`。

## 資料與隱私

- 預設不連線任何雲端服務。只有明確要求線上查詢、Papago 翻譯、開啟官方服務，或連結 ChatGPT 後送出問題時，才會使用網路。ChatGPT 問題由裝置直接傳給 OpenAI；短期對話脈絡只在記憶體，憑證以 Android Keystore 加密保存。Papago 原文只在明確翻譯時送往 Naver Cloud；其官方說明稱不保存原文，也不拿來訓練。查維基百科只會將查詢詞送往維基百科；台股查詢下載公開盤後資料，股票名稱或代號在手機比對。
- 分享給愛狐說的文字只在裝置上顯示及朗讀，不會因此送往 AI 服務或寫入檔案。
- 不需要位置權限，也不讀取或保存 GPS 座標。
- 已保存的上次裝置資訊位於 App 私有設定中，目前只儲存裝置名稱。
- Android 雲端備份與裝置移轉都排除 App 私有資料；ChatGPT 授權資訊另以 Android Keystore 加密。
- 氣象署、環境部與 Papago Secret 由使用者輸入，以 Android Keystore 加密保存在此裝置，只於相應的明確查詢或翻譯請求時送往服務。既有版本保存的這些授權資料會在首次啟動時加密遷移，成功後移除舊設定中的明文值。Papago Client ID 保存在 App 私有設定；Repository 不包含這些憑證。
- 匯出內容不包含裝置位址。目前版本未提供匯出功能。
- Repository 不應包含私人裝置資料、憑證或使用者匯出內容。
